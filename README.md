# Portfolio - Pedro Gustavo

Site de portfólio pessoal desenvolvido com React, Vite e Tailwind CSS.

## 🚀 Tecnologias

- React 18
- Vite
- Tailwind CSS
- Lucide React (ícones)

## 📦 Instalação

```bash
npm install
```

## 🔧 Desenvolvimento

```bash
npm run dev
```

O site estará disponível em `http://localhost:5173`

## 🏗️ Build

```bash
npm run build
```

## 👀 Preview do Build

```bash
npm run preview
```

## 📁 Estrutura do Projeto

```
portfolio-page/
├── public/
│   └── images/          # Imagens dos projetos (.webp, .png, .jpg)
├── src/
│   ├── App.jsx          # Componente principal
│   ├── main.jsx         # Entry point
│   └── index.css        # Estilos globais
├── index.html           # HTML base
├── package.json
├── vite.config.js
├── tailwind.config.js
└── postcss.config.js
```

## 🖼️ Como Adicionar Imagens dos Projetos

Coloque suas imagens em `public/images/` e atualize os caminhos em `src/App.jsx`.

**Formatos suportados:**
- ✅ **WebP** (recomendado - menor tamanho)
- ✅ PNG
- ✅ JPG
- ✅ SVG

**Guias disponíveis:**
- `COMO-ADICIONAR-IMAGENS.md` - Passo a passo completo
- `WEBP-SUPORTE.md` - Por que usar WebP
- `public/images/README.md` - Instruções detalhadas
